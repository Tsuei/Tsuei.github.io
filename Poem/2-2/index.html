    丙午下

    # 丙午下

    # 〇水龍吟

    # 子路

    慕前輩壯詞。變調演之。

    聖言由也迂之。乘桴相伴結纓死。賢七十二。復誰拚命。力行真理。不忮無求。縕袍衣敝。蔑恆榮恥。更憑河暴虎。浩然勇者。括且羽。鏃而礪。  雞冠戴豭豚佩。獻精誠。贍親負米。固無宿諾。未應衰減。少年銳氣。執轡周遊。振鐸天下。意和夫子。記儒門臂膀。心甘委質。一躬施禮。

    # 〇知迠黨節諸媒不臣哀歎痛恨題

    乙遊破事不足聊。洽適光榮七月幺。每自狎邪摘姿色。誰因加罪吝舌條。真龍一怒連寰海。王化無垠盪衰蕭。當頌至高無上主。莫愛相公愛君堯。

    # 〇裏切

    人間新鬼忍爲看。真乃罡星獸散前。法取孤絕得立己。昏承羣昧怎偏安。不相謀歎道皆異。以密成知事惟艱。倦夜羁身遭箭冷。始惜斯匪未清全。

    # 〇賀龍昕又奪全錦賽男雙冠

    蜀中大將思言廖。趙室疑難煩請頗。空望神國孰後起。既皆橫掃以塵轍。

    # 〇回鄉偶書

    大哉聖化布恩間。窮壤猶兇惡每傳。盼帝心重加偉力。屠黑五類與冥頑。

    # 〇溼瘡記

    余自孩提。膚之疲弱既異於常人。及縣學時。尾。左膕兼生二毒瘡。久不得醫。其症也。癢而欲撓。撓之瘡破。肉乃生痛。及痂結。即又復焉。嘗求醫於京。得藥膏方。搽拭未見症痊。徒使指添苦烈味。以爲無用。於是日日常與奇癢爛痛相伴。今方歸鄉。自知是乃真菌故者。覓以白藥膏塗之。遂愈。

    # 〇歸國判

    文明開化。判乎細末枝節。民風國格。全在微毫行事。自華夏入瀛洲。殊異未覺。以其同文種也。自瀛洲入華夏。德行不見。以其失禮教也。野而歸禮。以其清規固宜也。況人間相像。以爲故土吾鄉。是上兼容而先拳拳也。禮而歸野。以其風俗未化也。況家於自國。因更痛心浩歎。是下落差而後彷徨也。

    # 〇詠日左

    唐土佛光耀九瀛。真傳勁旅神國生。選集終日手中捧。敵寇三番夢裏征。結社武裝欲帝滅。屠資轉戰唱無興。華胥古莽真嘗在。舍利無窮法道行。

    # 〇自作解說

    何因韻事著鞭先。無以疏才付稗官。豈敢成章佳句要。姑求棲木喙聲完。謅填偏廢音轍老。譯製每嫌頓步難。好俾野夫千欲語。無非一念化刁蠻。

    # 〇滿江紅

    # 九日

    赤色規模。記宇內。煌煌樹立。吟斷處。山川亦老。人情頻易。車列驅馳南北鐵。雲樓排比東西峙。漸入秋。風起晚來急。寒侵體。  追往事。今無跡。嗟故國。隨潮去。把盞杯推換。襟懷新抑。洪武功名終一代。秦皇律令猶千世。懸彼頭。遺我大民族。自由日。

    # 〇金縷曲

    鳴鼓而攻戰。便從今。先生喑啞。烏臺公案。列敘諸人真老友。箇箇狼心賊膽。更誰信。嚶鳴啼囀。匪不限人人自限。笑奴僕。樂子悠然看。既亂世。重刑典。  周郎自審弦咊管。午寒輕。白日照舊。清風遙勸。小將脣槍難當了。灑下欺名長怨。歎何必。黑白置換。歌罷離騷拂袖去。此梁山。酷似金鑾殿。一鬭倒。二平反。

    # 〇觀『生化危機爆發夜』有感

    癘疫夜中百鬼囂。西方治下雪飄搖。屍油大煉擇優育。血肉濃香趁鮮嚼。得取劑針金萬祿。何幹草芥命一條。昂撒淪難大白舞。歌我清零德政朝。

    # 〇赤色亡以理想

    赤色諸國。莫不以理想亡。以務實興。列公締和約。斯氏誅叛黨。所以衛新政。太祖。波氏以貧弱而可以近共產。於是亡。金氏則重拾封建之權術。事大之舊例。而足以苟於今。故云。理想真毒害也。而方今自居左翼者。莫不爲烏有之國。浮誇之義所蠱惑。實污左翼之名。而行專橫跋扈之事也。其狂熱也盛。曾科學求是之不顧。誠危矣。蓋資本家。無產者。本一母同胎而生。其纏鬭往復。或百年。或千年。未可知也。馬公之謂共產也。蓋階級史之終結。自由史之發端也。嗚呼。何其遠矣。而急功近利。妄圖一日而成。不亦謬乎。但基督之天國在精神之天。我儕之天國在時間之末耳。

    # 〇譯文歐化辯

    讀外國小說譯本（如近所讀托馬斯·曼《浮士德博士》），即知不諳文言則不能知漢語原貌，於是不能書以漢語習慣表達，必使歐化語句氾濫而已。如綴形容詞之「的」，綴動詞以示體貌之「著」「了」「過」，漸虛化而爲冠詞之「一個」，繁複瑣碎之冗長句式等，闌入文脈。凡此歐習，不勝枚舉，多畧通異邦之言即可察之。此類雖覩譯文而還原泰西原文不難之文，蓋以其繁時態長從句等漢語之固無，尋諸白話之形似而對譯者也，佔譯文十之有九，以譯家各有高低取捨。其異宜所注目者，斯字斯詞，雖譯文白話文之所共有，惟源非一族，歐化文實譯家所草書面之方言，或無人循其例組織其言，若白話則筆端之口頭。而於今文壇，本土諸公，以世之佳作，多非漢聲，又罔通外語，自取法乎二手譯文，敷陳文章，歐化或猶甚矣，以其亦不通文言耳。雖有時運易風俗推白話之故，自詡文人而曾文脈之罔顧，世無二例。夫原文本非繁複，其語之癖使然，如名詞前易綴“你的/我的/他的”明之所屬，以其名詞於句不能獨存，不以此，則必以冠詞複數故也，況領詞冠詞，於其語僅一音節矣，於我則二，與我實詞相當，而西語實詞則三音四音者尚多。如此極自然而適一語之性者，移諸漢語則不然矣。然，此事不能全咎於譯者。直譯之益，在輸入新文及一方文脈，其異質之感，足以拓漢語一隅。若確鑿無誤，忠於作家者，雖體例硬直，過可免矣。案古者倭人仿作漢文闌入和習而爲變體漢文云者，歷代擬上古爲文言而必受時語方音之思維牽引者，蓋與方今歐化之習有同矣。至若漢習不通又謬誤實多者，宜速摒之。夫近世西學盛而舊學衰，現代學科分野，全仗譯文輸入，不獨乎文學藝術，是以有歐化者，並藉之成現代白話，別於舊白俗語，而以漢語中文普通話稱。昔時，又破文言，以爲桎梏鐐銬，更甚則有廢漢字之議。即今清朗太平，昔人救國狂熱之策，終可辯證審之。惟宜倡正聲，賡續語體精華耳。

    # 〇金縷曲

    # 弱歲生日

    我亦難知己。但隻身、千端俗務，煩雜爲計。休叫平生得知遇，屈指交遊幾子？更罔論、行情世勢。苦霧迷行途不見，歎二十年訖成底事！語爛肚，劍凝紫。  一盅燒酒寬羈旅。此鋼城、霾籠燈暈，嚴風仍起。自恃少年凌雲氣，看破塵囂箇裏。笑儒腐、心疲茲始。人共往事一合葬，蓋日月逾邁無能止。聊奏曲，充碑誌。
